# Agent Product Discovery

A simple static website for Agentic Shelf, an onboarding layer that helps emerging consumer brands become readable to AI shopping agents.

The site explains:

- why AI shopping changes product discovery
- how brands answer plain-language onboarding questions
- how those answers become a structured product passport
- how channel readiness and trust gaps are surfaced
- how shopping-intent visibility can be simulated
